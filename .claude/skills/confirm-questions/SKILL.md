# 確認題目

確認是家長核對後的標記（見 `GLOSSARY.md`）。agent 只照家長指定的範圍改，不自行判斷哪些題目「看起來沒問題」。

1. **確定範圍**：把家長的話換成明確的題目 ID 清單（題目 ID 是「題庫檔名-兩位數序號」，`no` 就是序號）。範圍說不清楚（例如「前面那些」）時先問。用 `pnpm list:questions <資料目錄>` 對照，確認每個 ID 都存在；不存在的 ID 回報給家長，不要猜。
2. **改欄位**：在對應的題庫檔裡，只把這些題目的 `confirmed` 改成 `true`（沒有這個欄位就加上），其他欄位與題目一律不動。該題上方有「# 不確定：」註解時，一併刪掉，因為家長已經核對過。
3. **檢查**：跑 `pnpm check:bank <資料目錄>`，直到輸出「題庫檢查通過」。
4. **回報**：確認了哪些 ID、哪些 ID 原本就已確認、哪些不存在。

資料目錄依序取：家長指定的目錄、環境變數 `EXAMREMIX_DATA_DIR`、repo 根目錄的 `data/`。
