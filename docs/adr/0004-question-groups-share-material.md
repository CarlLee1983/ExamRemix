# 共用材料的多題以題組保存

社會原卷的「配合題」是一段班會短文配 8 題選擇題，而原本「題目」只容許共用一張圖或表的多個空格屬於同一題，沒有讓多個題目共用材料的結構。可選的做法有三種：每題題幹重複整段短文（印出時重複 8 次）、只把短文放在第一題（拆開組卷後其餘題目讀不懂）、或新增**題組**。我們選擇題組：材料只存一次也只印一次，組卷時可只挑部分題目，但這些題目要在同一個大題連續排列、前面印出材料，衍生新題時以整組為單位；材料有疑點時整組不能使用，之後英語閱讀測驗等題型也沿用同一結構。代價是題目不再一律是可以單獨挑選的單位，組卷、衍生與疑點規則都要認得題組。

**Falsified if:** 實際匯入的原卷中，共用材料的題目都能改寫成不依賴材料的獨立題而不失考點，或題組只出現在這一份社會卷；此時應移除題庫 schema（`src/domain/schema.ts`）的題組結構，與跨檔檢查（`src/domain/bank-check.ts`）中的題組規則。
