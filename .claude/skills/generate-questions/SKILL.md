# 產生新題

用語以 `GLOSSARY.md` 為準。題型與各欄位的寫法以 `README.md` 為唯一依據，寫 YAML 前先讀它的「題型」以下各節；衍生規則見 `README.md` 的「題庫檢查」。

## 1. 確定原題與數量

把家長的話換成明確的原題 ID 清單與新題數量，數量不清楚時先問。資料目錄依序取：家長指定的目錄、環境變數 `EXAMREMIX_DATA_DIR`、repo 根目錄的 `data/`。

```sh
pnpm list:questions <資料目錄> --id <原題 ID> [--id <原題 ID> ...]
```

每個原題都必須：存在、已確認、本身是原題（有 `source`，不是 `derivedFrom` 的新題）。給了多題原題時，它們的題型、科目、年級、單元必須完全相同。任何一項不符就停下來告訴家長是哪一題、哪一項，不要換別的題目代替。

原題附圖（`image`）時，新題沒有對應的圖可用：只在新題不需要圖也能作答時才產生，否則告訴家長這題無法衍生。

完成條件：原題清單全部合格，數量確定。

## 2. 出題

讀原題的完整 YAML，產生新題：

- **繼承**：`type`、`subject`、`grade`、`unit` 與原題完全相同（單元沒寫就都不寫）；原題有 `space` 覆寫且新題長度相近時一併沿用。
- **變化**：換數字、情境、人名、詞語，保持同樣的考點與難度；新題之間、新題與原題之間不可重複。國語題換用同年級程度的字詞。
- **欄位**：`derivedFrom` 列出參考的所有原題 ID；不寫 `source`；`confirmed: false`，新題一律由家長確認。

## 3. 寫答案與解析並驗算

每題寫出答案與給家長看的解析。數學題逐題驗算：用與解題不同的方式再算一次（例如乘法用除法回推、加法用減法回推），兩次不一致就重出這題；直式計算的 `answer` 必須等於運算結果。

完成條件：每題都有答案與解析，數學題都驗算過且一致。

## 4. 寫題庫檔

一次產生的新題存成一個題庫檔：`<資料目錄>/bank/new-<第一個原題 ID>-<今天日期 YYYYMMDD>.yaml`，例如 `new-sample-math-26-20261027.yaml`；撞名時在後面加 `-2`、`-3`。`no` 從 1 起連續編號，題目 ID 會成為「題庫檔名-兩位數序號」。

## 5. 檢查到通過

```sh
pnpm check:bank <資料目錄>
```

有問題就修這次寫的題庫檔後重跑，直到輸出「題庫檢查通過」。問題出在其他檔案時，停下來告訴家長，不要動別的檔案。

完成條件：`pnpm check:bank` 以狀態碼 0 結束。

## 6. 回報

告訴家長：題庫檔路徑、新題 ID 與各自衍生自哪些原題、每題的答案，以及核對方式：`EXAMREMIX_DATA_DIR=<資料目錄> pnpm dev` 後到 `/bank/` 篩「未確認」核對；核對完自己把 `confirmed` 改成 `true`，或請 agent 確認（confirm-questions skill）。
