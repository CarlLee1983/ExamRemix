# 題庫、試卷與裁切圖不進公開 repo

原題的文字與插圖多半來自出版社或學校考卷，有著作權，也可能透露孩子就讀的學校；repo 卻是公開的 GitHub repo。因此題庫、試卷檔與從原卷裁切的圖，和原卷照片一樣以 `.gitignore` 排除，repo 只放程式、schema 與一份自己編寫的虛構範例題庫，供開發與測試使用。代價是題庫沒有版本歷史，換電腦時也不會跟著 clone 過來，需要自行備份。

**Falsified if:** repo 改為私有，或題庫只收錄自己編寫、沒有著作權疑慮的題目；此時讓題庫跟著 repo 版本控制會更簡單，`.gitignore` 中排除題庫與試卷的規則就可以移除。
