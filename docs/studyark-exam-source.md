# 考卷來源紀錄：學習方舟

狀態：已透過學習方舟列出的校方題庫取得原卷；目前依使用者確認，以國小三年級上學期期中考為題庫範圍。站內試卷下載流程與校方公開題庫的存取方式不同，見下方紀錄。

## 目標

- 來源：[學習方舟](https://www.studyark.org/)
- 範圍：國小三年級上學期期中考的數學、國語、英語、社會與自然考卷。
- 用途：取得少量有代表性的考卷，供 AI 參考題型並產生新題；不必大量收集，也不必使用每一道原題。
- 不需收集英文聽力音檔。
- 學校、學年度、出版社和份數尚未指定，先不限定；考試階段限定期中。

## 後續試抓

1. 從學習方舟的搜尋或分類尋找符合範圍的考卷，以少量檔案確認取得方式，取得足以參考題型的考卷即可。
2. 記錄每份考卷的來源網址、學校、學年度、學期、科目、考試階段、出版社及是否有答案；找不到的資訊標為待確認。
3. 與已取得的考卷比對重複內容。同一場考試的題目卷與答案卷配成一組，不因屬於同一場考試而丟棄其中一份。
4. 保存取得的原始檔，整理每科取得的份數，以及找不到、缺答案或受存取限制的情況。

## 後續匯入

取得考卷後再依專案當時的匯入流程處理。目前題庫支援的科目為國語、數學、社會與自然；英語的原卷可先保存，其匯入方式需另行處理。
