# 產生新題

用語以 `GLOSSARY.md` 為準。題型與各欄位的寫法以 `README.md` 為唯一依據，寫 YAML 前先讀它的「題型」以下各節；衍生規則見 `README.md` 的「題庫檢查」。

## 執行

依[本機新題品質流程](../../../docs/question-generation-workflow.md)處理獨立題或完整題組：固定來源、數量單位與考點，將候選及具體求解／近重證據保存在題庫外，再使用 `pnpm bank:generate` 完成有限重出、整批驗證及可靠入庫。

題組只給部分組員時，展開完整原組並列明新組數及小題總數；只有意圖或數量單位不明才詢問。材料與全部成員共同重新求解，一處失敗就重驗整組。來源資格不符或事實不明時，保留 ID 與缺口並停止。

各科題型格式沿用 [import-original 第 2 步](../import-original/SKILL.md#2-逐題讀出印刷內容)，社會及英語答案依據沿用其[第 3 步](../import-original/SKILL.md#3-寫答案與解析)。數學使用品質流程的明確模型與獨立驗算。

完成條件是可靠入口回傳 `published`；按品質流程回報題目／題組 ID、來源、答案、警告及預覽方式。拒絕、停止或已回復均不得宣稱新增容量。已入庫內容日後有疑點，交由 record-doubt 處理。
