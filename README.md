# ExamRemix

把手機拍的原卷照片或 PDF 交給 AI agent 分析，只保留題目（去除已作答的筆跡），存成結構化題庫；再由 AI 參考原題產生同題型的新題，最後在本機純靜態網頁上依題型排版，輸出 A4 可列印的試卷。

## 功能目標

- **匯入**：在 Claude Code 等 AI agent 中分析照片 / PDF，區分印刷題目與手寫作答，只保留題目
- **產生**：參考原題產生新題，並附上答案與解析
- **輸出**：依題型（選擇、是非、造句、數學問答……）套用不同版面與作答空間；網頁可切換成答案卷，列印預設為試卷，答案卷供家長對答

## 已定方向

| 面向 | 決定 |
| --- | --- |
| AI 執行方式 | 在本機的 AI agent（Claude Code）內執行，不在網頁呼叫 API |
| 網頁 | 純靜態網站，僅本機使用 |
| 題庫格式 | YAML（建置時以 schema 檢查後轉成 JSON） |
| 數學式 | LaTeX 子集，以 KaTeX 渲染；直式計算等以結構化資料表示 |
| 紙張 | 只支援 A4，以 CSS `@page` 控制 |

詳細設計與決策紀錄見 `docs/adr/`，用語見 `GLOSSARY.md`。

## 開始使用

Node.js 版本需求見 `package.json` 的 `engines`，套件管理用 pnpm（版本見 `package.json` 的 `packageManager`）。

```sh
pnpm install
pnpm dev           # 開發伺服器，試卷在 /papers/<試卷檔名>/
pnpm build         # 建置靜態網站到 dist/
pnpm preview       # 預覽建置結果
```

網站有三個入口，都是純靜態、唯讀：

- `/`：首頁，連到下面兩頁。
- `/papers/`：試卷列表，列出所有試卷（標題、科目、年級、題數），連到各自的試卷頁 `/papers/<試卷檔名>/`，在那裡切換試卷與答案卷、列印。
- `/bank/`：題庫瀏覽，列出題庫所有題目（含未確認），每題顯示 ID（可選取複製，貼進試卷檔引用）、科目、年級、單元、題型、確認狀態、出處或衍生自哪些題目，以及答案與解析。可依科目、年級、單元、題型、確認狀態篩選，條件可組合；篩選條件會寫進網址，例如 `/bank/?confirmed=false` 就是待確認清單，可以直接加書籤。

### 確認題目

匯入的原題與產生的新題一開始都是未確認，不能放進試卷。核對流程：開啟 `/bank/?confirmed=false`（或在題庫瀏覽頁把確認狀態篩成「未確認」），逐題核對題幹、答案與解析；沒問題就到題庫 YAML 把該題的 `confirmed` 改為 `true`，或請 agent 幫你確認一個範圍的題目。改完重新建置（`pnpm dev` 會自動更新）即可。

### 在 Claude Code 裡請 agent 做

repo 內附四個專案 skill（`.claude/skills/`），在 Claude Code 裡直接用口語提出即可，例如「匯入 inputs/ 裡這份考卷」：

| skill | 做什麼 |
| --- | --- |
| `import-original` | 把一份原卷（多張照片或一份 PDF）匯入成一個題庫檔，題目一律未確認，回報題數與不確定的題目 |
| `confirm-questions` | 把你核對過的一個範圍的題目標記為已確認 |
| `generate-questions` | 參考已確認的原題產生同題型的新題，存成一個題庫檔 |
| `compose-paper` | 依科目、年級、單元、題型與題數，從已確認的題目組成一份試卷檔 |

每個 skill 完成前都會跑 `pnpm check:bank`，修到沒有問題為止。挑題時用的 `pnpm list:questions` 見「題庫檢查」。

### 指定資料目錄

網站從資料目錄讀題庫與試卷：`<資料目錄>/bank/*.yaml` 是題庫檔，`<資料目錄>/papers/*.yaml` 是試卷檔。預設讀 repo 內虛構的 `examples/`；用環境變數 `EXAMREMIX_DATA_DIR` 改指真實資料目錄：

```sh
EXAMREMIX_DATA_DIR=data pnpm dev
```

建議把真實資料放在 repo 根目錄的 `data/`，它已被 `.gitignore` 排除（見 ADR 0001）。題庫檔或試卷檔格式有誤時，建置會失敗並指出檔案與欄位。

### 題庫檢查

```sh
pnpm check:bank [資料目錄]    # 沒給參數時依序取 EXAMREMIX_DATA_DIR、examples
```

檢查資料目錄裡的題庫檔與試卷檔：檔名是否合格（只能用小寫英數字與連字號，如 `sample-math.yaml`）、格式是否符合 schema，以及跨檔規則：題目 ID 不可在題庫檔之間重複；題目的附圖（`image.src`）必須存在於 `bank/` 底下；新題（`derivedFrom`）的衍生規則（見下）；試卷只能引用存在的題目；試卷只能引用已確認的題目（未確認但沒被試卷引用的題目沒問題）。

衍生規則，逐一檢查新題的每個原題：原題必須存在；必須已確認；本身必須是原題（有 `source`，新題只能衍生自原題，不能衍生自新題）；題型、科目、年級、單元都要與新題一致（單元連「沒有」也要一致，一個原題回報一次並列出不一致的欄位）；衍生自多個原題時，這些原題彼此的四個欄位也要一致。每個問題輸出一行（檔案、欄位或題目 ID、說明），最後一行是摘要；有問題以狀態碼 1 結束，沒有問題以 0 結束，資料目錄或 `bank/`、`papers/` 不存在時也非零結束。`pnpm build` 會跑同一套跨檔檢查，有任何問題就失敗並列出全部問題。agent 匯入或產生題目後應先跑這個指令，修到沒有問題為止。

```sh
pnpm list:questions [資料目錄] [過濾條件]
```

列出題庫裡的題目，每題一行，欄位以 tab 分隔：題目 ID、題型、科目、年級、單元（沒有則 `-`）、`confirmed` 或 `unconfirmed`、題幹（換行壓成空格）。過濾條件都選填、彼此 AND，同一個旗標重複給值則是 OR：`--confirmed`、`--unconfirmed`、`--subject <科目>`、`--grade <年級>`、`--unit <單元>`、`--type <題型>`、`--id <題目 ID>`，例如 `pnpm list:questions --unconfirmed --type choice --grade 3`。沒有符合的題目時沒有輸出、狀態碼仍是 0；資料目錄不存在或旗標錯誤以 2 結束。格式不合 schema 的題庫檔會跳過並在 stderr 提醒先跑 `pnpm check:bank`。

### 題型

每題都有共用欄位（`no`、`type`、`subject`、`grade`、選填的 `unit`、`stem`、`explanation`、`confirmed`、選填的 `image` 與 `space`，以及原題的 `source` 或新題的 `derivedFrom` 擇一），再加上各題型自己的欄位：

| `type` | 欄位 | 說明 |
| --- | --- | --- |
| `choice` | `options`（2 至 6 個）、`answer`（1 起算的選項編號） | 題幹下方列出選項，留一個作答括號 |
| `true-false` | `answer`（`true` 或 `false`） | 留一個作答括號；答案卷填 ○（true）或 ✕（false） |
| `fill-blank` | `answer`（字串陣列，每個空格一個答案，不可為空字串） | 題幹用連續三個半形底線 `___` 標記一個空格 |
| `char-to-zhuyin` | 只有 `stem`，沒有 `answer` | 題幹中的注音標注就是要考的字（至少一個）：試卷上該字加底線，後面留注音作答格，寬度依注音組數 |
| `zhuyin-to-char` | 只有 `stem`，沒有 `answer` | 題幹中的注音標注就是要考的字（至少一個）：試卷上該字換成空白作答格（每字一格），注音以 ruby 顯示在格子上方 |
| `make-sentence` | `answer`（範例句子，非空字串） | `stem` 寫說明與詞語；題幹下方留預設行數的作答行（預設 2 行，見 `src/domain/answer-space.ts`），答案卷在行上以紅字顯示範例句子 |
| `imitate-sentence` | `example`（例句，非空字串）、`answer`（範例句子，非空字串） | 題幹下方另起一行顯示「例句：…」，再留同造句的作答行 |
| `horizontal-calc` | `answer`（字串或數字，可含數學式） | `stem` 寫算式與結尾的等號，例如 `$36 + 48 =$`；題幹後接一條答案底線，下方留計算區（預設 2 行，見 `src/domain/answer-space.ts`），答案卷在底線上以紅字顯示答案 |
| `vertical-calc` | `operands`（2 個以上非負數字，字串或數字，只含數字與最多一個小數點）、`operator`（`+`、`-`、`×`）、`answer`（數字，字串或數字） | `stem` 寫說明（如「用直式計算。」）；運算元排成直式，每個數字一格：加減法依小數點對齊，乘法靠右對齊；運算子在最後一個運算元列的最左欄，其下一條橫線，再留答案列（預設 1 列，見 `src/domain/answer-space.ts`），答案卷在答案列以紅字顯示。題庫檢查會以精確運算核對 `answer`（以數值比較，`12.50` 等於 `12.5`），減法結果不可為負 |
| `word-problem` | `answer`（答句，不含「答：」前綴，可含數學式） | 題幹下方是標有「算式：」的框線計算區（預設 4 行，見 `src/domain/answer-space.ts`），再接「答：」與一條橫線；答案卷在橫線上以紅字顯示答句 |

填空題的空格數必須等於 `answer` 的長度，且至少一個空格，答案依空格出現的順序排列，例如：

```yaml
- no: 27
  type: fill-blank
  stem: "3 公尺 = ___ 公分；1 公里 = ___ 公尺。"
  answer: ["300", "1000"]
```

試卷上空格渲染成底線，寬度依該空格答案的字數決定，不會印出 `___`；答案卷把答案以紅字填在底線上，底線寬度不變。

### 注音標注

所有題型的所有文字欄位（題幹、選項、解析、填空答案、造句的例句與答案）都能在任何字上加注音，寫法是 `[字|注音]`；多字寫成 `[公園|ㄍㄨㄥ ㄩㄢˊ]`，注音以半形空白分隔，組數必須等於字數，每組注音由注音符號（ㄅ–ㄩ）組成，輕聲 ˙ 只能放最前面，其他聲調（ˊ ˇ ˋ）最多一個且放最後，例如 `ㄉㄜ˙` 要寫成 `˙ㄉㄜ`。字數以字素計，帶異體字選擇符的字算一個字。沒有 `|` 的 `[...]` 一律當一般文字。頁面上每個字渲染成一個 `<ruby>`，注音橫排在字的上方。標注格式有誤（組數不符、非法注音、未閉合）時，題庫檢查與建置會指出題目與欄位。

```yaml
- no: 8
  type: char-to-zhuyin
  stem: "小明到[公園|ㄍㄨㄥ ㄩㄢˊ]散步。"   # 要考「公園」的注音
- no: 9
  type: imitate-sentence
  stem: "照樣造句。"
  example: "月亮像一個大銀盤掛在天上。"
  answer: "太陽像一顆大火球掛在天上。"
```

### 數學式

所有題型的所有文字欄位（題幹、選項、解析、各種 `answer`、例句）都能寫行內數學式：用 `$...$` 包住 LaTeX，例如 `$\frac{3}{4} + \frac{1}{4} =$`；字面的錢字號寫成 `\$`。數學式在建置時由 KaTeX 渲染，CSS 與字型都打包在站內，不需要網路。數學式的內容不做注音解析，數學式以外的文字照常支援注音標注。數學式未閉合、空的 `$$`、或 KaTeX 無法解析的 LaTeX，題庫檢查與建置都會指出題目與欄位。填空題答案含數學式時，底線寬度以原始 LaTeX 的長度估算。

```yaml
- no: 29
  type: horizontal-calc
  stem: "$36 + 48 =$"
  answer: 84
- no: 33
  type: vertical-calc
  stem: "用直式計算。"
  operands: ["4.6", "2.75"]
  operator: "+"
  answer: "7.35"
```

### 附圖與作答空間

任一題型都可以附圖：`image: { src: "sample-math/39.svg", alt: "替代文字" }`。`src` 是相對於 `bank/` 的路徑，圖片檔與題庫檔放在一起（建議每個題庫檔一個同名子目錄），副檔名限 png、jpg、jpeg、gif、svg、webp（不分大小寫）；不可是絕對路徑、不可含 `..` 或反斜線。圖片顯示在題幹之後，試卷與答案卷都有，建置時由 `/bank-images/` 端點原樣輸出，不需要網路。引用的圖片不存在時，題庫檢查會指出題庫檔、題目與圖片路徑。

每個題型有預設作答空間，單位是行；題目可以用 `space`（0 以上的整數）覆寫，預設值與意義集中在 `src/domain/answer-space.ts`：

| 題型 | 預設 | `space` 的意義 |
| --- | --- | --- |
| `make-sentence`、`imitate-sentence` | 2 | 作答行數；至少 1，不可為 0 |
| `horizontal-calc` | 2 | 計算區的高度 |
| `word-problem` | 4 | 算式計算區的高度 |
| `vertical-calc` | 1 | 橫線下方的列數，答案在最後一列；至少 1，不可為 0 |
| 其他題型 | 0 | 題目下方額外留白的高度，0 時不留 |

### 測試

```sh
pnpm check         # 型別檢查
pnpm test          # Vitest：schema 與題庫檢查單元測試、檢查指令測試，與較慢的建置失敗整合測試
pnpm test:e2e      # Playwright：以範例資料建置後測試試卷頁與 A4 列印
```

首次跑 `test:e2e` 前需要 `pnpm exec playwright install chromium`。

### 答案卷與列印

試卷頁上方的切換鈕可在試卷與答案卷之間切換：答案卷把選擇題與是非題的答案以紅字填進作答括號、填空題的答案填在底線上、國字注音與注音寫國字的答案填在作答格內、造句類的範例句子填在作答行上，並在每題下方顯示解析。載入頁面時一律是試卷，切換狀態不保存。列印跟隨當下的顯示模式：沒切換就印出試卷（不含答案與解析），切換成答案卷後再列印則含答案與解析；切換鈕本身不會印出。

## 隱私

原卷照片 / PDF 放在 `inputs/`，已被 `.gitignore` 排除，不會推上 GitHub。
