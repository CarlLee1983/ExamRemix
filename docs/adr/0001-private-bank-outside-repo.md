# 題庫、試卷與裁切圖納入 Git，原卷留在本機

2026-10-30 依使用者確認更新：專案要提供線上依範圍隨機組卷，正式部署使用 `data/`，所以 `data/bank/` 的題庫與附圖、`data/papers/` 的試卷納入 Git，讓遠端建置取得相同資料，也讓程式和資料一起追蹤版本。這取代原本「題庫僅供本機使用、不進公開 repo」的決定；代價是這些內容會隨 repo 及網站提供給讀者，包含答案、解析與來源。

原卷照片／PDF（`inputs/`）、`data/` 底下的封存、操作紀錄與工具快取仍留在本機。`examples/` 保留供開發與自動測試使用；正式預覽與部署明確選擇 `data/`，找不到時失敗，不退回範例。

**Falsified if:** 產品改為每個使用者持有獨立且不公開的題庫；此時應重新決定資料的儲存、同步與存取邊界。
