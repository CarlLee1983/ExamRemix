# 固定完整卷配置，以限制條件抽題及重抽

既有原型以大題區塊搭配，只能驗證版面；現有練習卷及節選原題也不能直接證明各科完整卷能力。我們選擇首版每科一份固定的改編完整練習卷配置，保留大題、考點、題型、題量與100分配分，隨機只替換符合槽位的題目；英語限定讀寫。相較單看題型數量抽題，需先核對候選與來源、檢查整卷可行性，但能避免滿足總題數卻偏離考點或缺少題組的卷子。

使用者確認：原題／新題不設比例，同卷禁止同源題與已確認近重題；題組保留材料與連續排列，允許按配置節選成員。重抽至少替換三分之一題目，調序不算差異；不滿足時保留仍合格的上一卷並說明，不減題、不補不確定題，也不立刻擴充正式題庫。代價是原始題數很多仍可能無法組卷或重抽，不能靠放寬規則讓操作看似成功。

已確認配額、來源界線、搜尋／重抽結果與驗收案例見[完整卷配置與抽題契約](../paper-composition-contract.md)。此決策不代表候選清單、來源核對、抽題器或列印驗收已完成。

**Falsified if:** 使用者需要多套配置或自訂題數，或改為接受同源共卷／較小重抽差異；應以新配置版本重新驗收，不在同版默默減少要求。
