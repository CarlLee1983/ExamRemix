# ExamRemix

把手機拍的原卷照片或 PDF 交給 AI agent 分析，只保留題目（去除已作答的筆跡），存成結構化題庫；再由 AI 參考原題產生同題型的新題，最後在本機純靜態網頁上依題型排版，輸出 A4 可列印的試卷。

## 功能目標

- **匯入**：在 Claude Code 等 AI agent 中分析照片 / PDF，區分印刷題目與手寫作答，只保留題目
- **產生**：參考原題產生新題，並附上答案與解析
- **輸出**：依題型（選擇、是非、造句、數學問答……）套用不同版面與作答空間；網頁可切換成答案卷，列印預設為試卷，答案卷供家長對答

## 已定方向

| 面向 | 決定 |
| --- | --- |
| AI 執行方式 | 在本機的 AI agent（Claude Code）內執行，不在網頁呼叫 API |
| 網頁 | 純靜態網站，僅本機使用 |
| 題庫格式 | YAML（建置時以 schema 檢查後轉成 JSON） |
| 數學式 | LaTeX 子集，以 KaTeX 渲染；直式計算等以結構化資料表示 |
| 紙張 | 只支援 A4，以 CSS `@page` 控制 |

詳細設計與決策紀錄見 `docs/adr/`，用語見 `GLOSSARY.md`。

## 開始使用

Node.js 版本需求見 `package.json` 的 `engines`，套件管理用 pnpm（版本見 `package.json` 的 `packageManager`）。

```sh
pnpm install
pnpm dev           # 開發伺服器，試卷在 /papers/<試卷檔名>/
pnpm build         # 建置靜態網站到 dist/
pnpm preview       # 預覽建置結果
```

### 指定資料目錄

網站從資料目錄讀題庫與試卷：`<資料目錄>/bank/*.yaml` 是題庫檔，`<資料目錄>/papers/*.yaml` 是試卷檔。預設讀 repo 內虛構的 `examples/`；用環境變數 `EXAMREMIX_DATA_DIR` 改指真實資料目錄：

```sh
EXAMREMIX_DATA_DIR=data pnpm dev
```

建議把真實資料放在 repo 根目錄的 `data/`，它已被 `.gitignore` 排除（見 ADR 0001）。題庫檔或試卷檔格式有誤時，建置會失敗並指出檔案與欄位。

### 題庫檢查

```sh
pnpm check:bank [資料目錄]    # 沒給參數時依序取 EXAMREMIX_DATA_DIR、examples
```

檢查資料目錄裡的題庫檔與試卷檔：檔名是否合格（只能用小寫英數字與連字號，如 `sample-math.yaml`）、格式是否符合 schema，以及三條跨檔規則：題目 ID 不可在題庫檔之間重複、試卷只能引用存在的題目、試卷只能引用已確認的題目（未確認但沒被試卷引用的題目沒問題）。每個問題輸出一行（檔案、欄位或題目 ID、說明），最後一行是摘要；有問題以狀態碼 1 結束，沒有問題以 0 結束，資料目錄或 `bank/`、`papers/` 不存在時也非零結束。`pnpm build` 會跑同一套跨檔檢查，有任何問題就失敗並列出全部問題。agent 匯入或產生題目後應先跑這個指令，修到沒有問題為止。

### 題型

每題都有共用欄位（`no`、`type`、`subject`、`grade`、選填的 `unit`、`stem`、`explanation`、`confirmed`，以及原題的 `source` 或新題的 `derivedFrom` 擇一），再加上各題型自己的欄位：

| `type` | 欄位 | 說明 |
| --- | --- | --- |
| `choice` | `options`（2 至 6 個）、`answer`（1 起算的選項編號） | 題幹下方列出選項，留一個作答括號 |
| `true-false` | `answer`（`true` 或 `false`） | 留一個作答括號；答案卷填 ○（true）或 ✕（false） |
| `fill-blank` | `answer`（字串陣列，每個空格一個答案，不可為空字串） | 題幹用連續三個半形底線 `___` 標記一個空格 |
| `char-to-zhuyin` | 只有 `stem`，沒有 `answer` | 題幹中的注音標注就是要考的字（至少一個）：試卷上該字加底線，後面留注音作答格，寬度依注音組數 |
| `zhuyin-to-char` | 只有 `stem`，沒有 `answer` | 題幹中的注音標注就是要考的字（至少一個）：試卷上該字換成空白作答格（每字一格），注音以 ruby 顯示在格子上方 |
| `make-sentence` | `answer`（範例句子，非空字串） | `stem` 寫說明與詞語；題幹下方留預設行數的作答行（見 `SentenceLines.astro` 的 `SENTENCE_LINES`），答案卷在行上以紅字顯示範例句子 |
| `imitate-sentence` | `example`（例句，非空字串）、`answer`（範例句子，非空字串） | 題幹下方另起一行顯示「例句：…」，再留同造句的作答行 |

填空題的空格數必須等於 `answer` 的長度，且至少一個空格，答案依空格出現的順序排列，例如：

```yaml
- no: 27
  type: fill-blank
  stem: "3 公尺 = ___ 公分；1 公里 = ___ 公尺。"
  answer: ["300", "1000"]
```

試卷上空格渲染成底線，寬度依該空格答案的字數決定，不會印出 `___`；答案卷把答案以紅字填在底線上，底線寬度不變。

### 注音標注

所有題型的所有文字欄位（題幹、選項、解析、填空答案、造句的例句與答案）都能在任何字上加注音，寫法是 `[字|注音]`；多字寫成 `[公園|ㄍㄨㄥ ㄩㄢˊ]`，注音以半形空白分隔，組數必須等於字數，每組注音由注音符號（ㄅ–ㄩ）組成，輕聲 ˙ 只能放最前面，其他聲調（ˊ ˇ ˋ）最多一個且放最後，例如 `ㄉㄜ˙` 要寫成 `˙ㄉㄜ`。字數以字素計，帶異體字選擇符的字算一個字。沒有 `|` 的 `[...]` 一律當一般文字。頁面上每個字渲染成一個 `<ruby>`，注音橫排在字的上方。標注格式有誤（組數不符、非法注音、未閉合）時，題庫檢查與建置會指出題目與欄位。

```yaml
- no: 8
  type: char-to-zhuyin
  stem: "小明到[公園|ㄍㄨㄥ ㄩㄢˊ]散步。"   # 要考「公園」的注音
- no: 9
  type: imitate-sentence
  stem: "照樣造句。"
  example: "月亮像一個大銀盤掛在天上。"
  answer: "太陽像一顆大火球掛在天上。"
```

### 測試

```sh
pnpm check         # 型別檢查
pnpm test          # Vitest：schema 與題庫檢查單元測試、檢查指令測試，與較慢的建置失敗整合測試
pnpm test:e2e      # Playwright：以範例資料建置後測試試卷頁與 A4 列印
```

首次跑 `test:e2e` 前需要 `pnpm exec playwright install chromium`。

### 答案卷與列印

試卷頁上方的切換鈕可在試卷與答案卷之間切換：答案卷把選擇題與是非題的答案以紅字填進作答括號、填空題的答案填在底線上、國字注音與注音寫國字的答案填在作答格內、造句類的範例句子填在作答行上，並在每題下方顯示解析。載入頁面時一律是試卷，切換狀態不保存。列印跟隨當下的顯示模式：沒切換就印出試卷（不含答案與解析），切換成答案卷後再列印則含答案與解析；切換鈕本身不會印出。

## 隱私

原卷照片 / PDF 放在 `inputs/`，已被 `.gitignore` 排除，不會推上 GitHub。
