# 匯入原卷

用語以 `GLOSSARY.md` 為準。題型與各欄位的寫法（含注音標注、數學式、附圖、作答空間）以 `README.md` 為唯一依據，寫 YAML 前先讀它的「題型」以下各節。

## 1. 確定輸入與輸出

- 輸入：一份原卷，可能是多張照片（依頁序）或一份多頁 PDF，通常放在 `inputs/`（已被 git 忽略）。一次只匯入一份原卷；家長給了多份時，一份一份做。
- 資料目錄依序取：家長指定的目錄、環境變數 `EXAMREMIX_DATA_DIR`、repo 根目錄的 `data/`。不要寫進 `examples/`，除非家長明說要做範例。
- 題庫檔名：只用小寫英數字與連字號，描述這份原卷，例如 `g3-math-u4-quiz-2026-10`；不得含孩子姓名或學校名稱，也不和 `<資料目錄>/bank/` 既有檔名撞名。題目 ID 會自動成為「題庫檔名-兩位數序號」，所以 `no` 從 1 起連續編號。

PDF 先轉成每頁一張圖，放在 scratchpad（不放進資料目錄）：

```sh
pdftoppm -r 200 -png <原卷.pdf> <scratchpad>/page
```

完成條件：每一頁都有一張可讀的圖，題庫檔名與資料目錄確定。

## 2. 逐題讀出印刷內容

一頁一頁、一題一題讀。原卷上的東西分兩類，只有**印刷**的那一類進題庫：

| 保留（印刷） | 排除（筆跡與批改） |
| --- | --- |
| 題號、題幹、選項、例句、印刷的數字與算式 | 孩子寫的答案、圈選、劃記、塗改、擦掉的痕跡 |
| 印刷的插圖、圖表、幾何圖形 | 老師的勾叉、紅筆訂正、分數、評語、印章 |
| 大題完整標題、說明與配分（保存在 `source.section`） | 頁首的姓名、座號、班級、學校、家長簽名 |

- 被作答填掉的空格還原成空格：填空寫回 `___`，作答括號不寫進題幹（題型元件會自己畫）。
- 印刷文字被筆跡蓋住、讀不出來時，依上下文寫出最可能的版本，並為這題記下疑點。
- 需在圖或表格的原空格作答時，完整保留為一題，以 `diagram-label` 或 `table-fill` 表達原空格；勾選題用 `multi-select`，保留文字、圖片或圖文選項。
- 只支援 `README.md` 題型表中的題型。連線題、排序題、閱讀測驗等其他形式不匯入，記下原卷題號，最後回報。

每題判斷：`type`（依作答形式對照題型表）、`subject`（依 README 的支援科目）、`grade`（原卷標示的年級，沒有標示時依內容判斷並記下疑點）、`unit`（每題至多一個；不同題可屬於不同單元，原卷有單元名稱就用，否則依內容判斷，無法確定可省略）。

完成條件：原卷上每一題都已寫成題目，或記入「未匯入」清單。

## 3. 寫答案與解析

區分印刷答案與孩子的作答：原卷附有印刷答案時逐題核對題意與答案；孩子的作答不能當正確答案用，即使看起來是對的。

- 每題獨立解題並核對印刷答案，若兩者不一致就記下疑點；將解答寫進題型要求的答案欄位，`explanation` 寫給家長看得懂的解析。
- 數學題逐題驗算：橫式與應用題重算一次，直式計算的 `answer` 必須等於運算結果（題庫檢查也會擋）。
- 國語題（注音、造句、照樣造句）寫標準答案或範例句；字音、字形沒有把握時記下疑點。

## 4. 裁切插圖

題目或選項有插圖、圖表或幾何圖形時，從原卷圖裁下只含印刷內容的區塊（不含孩子在圖上的作答），存成 `<資料目錄>/bank/<題庫檔名>/<兩位數序號>.png`（同題多張圖時加 `-option-1` 等後綴區分），題目以相對於 `bank/` 的路徑引用（寫法見 `README.md` 的附圖一節）：

```sh
magick <scratchpad>/page-1.png -crop <寬>x<高>+<左>+<上> +repage <資料目錄>/bank/<題庫檔名>/05.png
```

裁完先在 scratchpad 看一次每張圖，檢查圖完整且不含印刷答案、孩子作答或批改標記，才放進 `bank/`；無法取得乾淨圖時不匯入該題，記下原卷位置與原因。為題目、選項及表格欄標題的每張圖寫出描述可見內容的 `alt`，核對各 `src` 指向實際檔案；圖示標示題另按乾淨圖片量出 `labels` 的空格位置與大小，位置在第 6 步實際顯示核對；表格題按原欄列順序填寫 `columns`、`rows`。

## 5. 寫題庫檔

寫到 `<資料目錄>/bank/<題庫檔名>.yaml`，每題：

- `source`：`originalPaper` 寫原卷名稱（描述科目、年級、單元或日期，不含孩子姓名與學校名稱），`section` 保存原卷大題完整標題、說明與配分文字；`number` 只寫原印的小題號，沒有就省略。`section`、`number` 至少一個存在，不用題庫的 `no` 代填來源題號。
- `doubt`：前面記下疑點的題目寫一句說明，讓家長知道要核對什麼，例如 `doubt: 第二個選項被塗改蓋住，依上下文推定為「42」`。其餘題目不寫 `doubt`，直接可用。

寫完後搜尋整個題庫檔與裁切圖檔名，檢查沒有出現孩子的姓名或孩子的作答內容。

## 6. 檢查到通過

```sh
pnpm check:bank <資料目錄>
```

有錯誤就修這次寫的題庫檔或裁切圖後重跑；錯誤出在其他檔案時，停下來告訴家長，只改這次寫的檔案。

有圖示標示題時，執行 `EXAMREMIX_DATA_DIR=<資料目錄> pnpm dev`，開 `/bank/?type=diagram-label` 並展開各題後截圖，逐題對照原卷，確認每個空格都蓋在原卷空格上；對不準就修正 `labels` 後重看，無法判斷才記下疑點。這一步由 agent 完成，不交給家長逐題核對。

完成條件：摘要是 0 個錯誤（狀態碼 0），或其他檔案的錯誤已回報給家長；每題圖示標示題的空格都已核對對準，或已記下疑點。

## 7. 回報

告訴家長：題庫檔路徑、匯入題數、裁切圖數、未匯入的原卷題號與原因、`check:bank` 的每一則警告，以及帶疑點的題目。網站不顯示疑點，所以帶疑點的題目要在回報中逐題列出：題目 ID、疑點說明、原卷位置（頁與題號），請家長對照原卷判斷。判斷後可以請 agent 修正題目，或解除疑點（record-doubt skill）。之後想再查，用 `pnpm list:questions <資料目錄> --doubt`。
