# 每題單一考試範圍，只發布合格試卷

網站依年級、學期、期中／期末與科目選卷，但既有 schema 缺少學期與考試階段，封存或檔名也不能證明分類。我們選擇每題明確記錄一份考試範圍，新題嚴格繼承原題，題組由成員推導且須一致，試卷另宣告相同範圍；首版只啟用三上期中五科。相較檔案或資料目錄統一標記，逐題保存需要較多資料核對，但保留既有 ID 與混合檔案的能力，避免遺失分類或跨範圍借題。

使用者在 #47 確認：不保留含範圍未知或有效疑點題目的舊試卷網址與列印能力。這**部分取代 ADR 0003** 的既有卷只警告規則；保留來源檔、ID、附圖與引用供修正及回復，不等於仍發布該試卷。代價是既有書籤可能失效，部署時也必須移除舊產物；不以更換題目或縮減題量維持原網址可用。

完整欄位、容量、遷移與驗收見[考試範圍與可用容量契約](../exam-scope-contract.md)。這是決策文件，尚未修改程式或遷移正式資料。

**Falsified if:** 必須讓同一題有多個明確適用範圍，或使用者改為要求不合格舊卷仍可公開使用；屆時重新決定分類與發布邊界，不藉複製 ID 或隱性跨範圍借題繞過。
