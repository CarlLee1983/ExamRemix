# 組卷

用語以 `GLOSSARY.md` 為準；試卷檔的欄位與資料目錄的結構見 `README.md`（「指定資料目錄」「題庫檢查」兩節）。

## 1. 確定要求

從家長的話整理出：科目、年級、單元（可多個或不限）、每種題型的題數、試卷標題、選填的各大題配分。試卷只有一個科目與一個年級；要求跨科目或跨年級時，先問家長要拆成幾份。

資料目錄依序取：家長指定的目錄、環境變數 `EXAMREMIX_DATA_DIR`、repo 根目錄的 `data/`（存在時）。都沒有就問家長，不要寫進 `examples/`，除非家長明說要做範例。

完成條件：每種題型都有明確題數，資料目錄確定。

## 2. 挑題

```sh
pnpm list:questions <資料目錄> --no-doubt --subject 數學 --grade 3 [--unit 乘法] [--type choice]
```

每行一題：ID、題型、科目、年級、單元、疑點（`doubt` 或 `-`）、題幹。只從 `--no-doubt` 的結果挑；有疑點的題目一律不放進試卷，即使家長要求的題數不夠。

- 每種題型挑到家長要的題數，同一題不重複出現。
- 單元有多個時盡量平均分配；原題與衍生自它的新題（`derivedFrom`）避免放在同一份試卷。
- 某題型沒有疑點的題目不夠時，放進所有夠格的題目，記下缺幾題；再把 `--no-doubt` 換成 `--doubt`、其餘條件不變，列出因疑點被排除的題目，最後一併回報。缺額只用同單元、同題型的題目補。

完成條件：每個要求的題型都挑滿，或已記下缺額。

## 3. 寫試卷檔

寫到 `<資料目錄>/papers/<檔名>.yaml`。檔名只用小寫英數字與連字號，不和既有試卷檔撞名（例如 `math-g3-multiplication-1`）。

- 預設一種題型一個大題，大題標題用「一、選擇題」「二、是非題」這樣的中文序號；家長另有分法時照家長的。
- 家長給了配分才寫 `points`。

完成條件：試卷檔已寫入，每個大題的題目 ID 都來自第 2 步挑出的題目。

```yaml
title: 三年級數學乘法練習
subject: 數學
grade: 3
sections:
  - title: 一、選擇題
    points: 40
    questions: [sample-math-01, sample-math-02]
```

## 4. 檢查到通過

```sh
pnpm check:bank <資料目錄>
```

有錯誤就修試卷檔（換掉不存在的 ID、修檔名或欄位）後重跑；這次寫的試卷檔出現疑點警告，表示挑到了有疑點的題目，換掉它。只改這次寫的試卷檔；錯誤出在其他檔案時，停下來告訴家長。

完成條件：摘要是 0 個錯誤（狀態碼 0），沒有指向這次試卷檔的疑點警告，或其他檔案的錯誤已回報給家長。

## 5. 回報

告訴家長：試卷檔路徑、各大題的題目 ID、缺額（哪個題型少幾題、哪些題目因疑點被排除）、`check:bank` 的每一則警告，以及預覽方式 `EXAMREMIX_DATA_DIR=<資料目錄> pnpm dev` 後開 `/papers/<檔名>/`。
