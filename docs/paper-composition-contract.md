## 已確認的固定配置

使用者已逐輪確認：每科一份固定配置、每卷100分；同源及已確認近重禁止共卷；重抽至少替換三分之一；英語只提供讀寫完整卷；原題／新題沒有固定比例且可全為原題；採用下列具體配額作為**改編完整練習卷**，不宣稱原卷逐題復刻。

題數依不同題目 ID 計，整組配對、整張表及完整圖題各算一題；空格、配對端點與材料不另加題數，閱讀小題則各算一題。下表數字為「題數 × 每題滿分 = 大題滿分」。各大題依列出順序排列，不隨機增刪或更換題型。

「做做看／選擇」「國字注音／字詞填寫」即使同為一個 schema 題型，考點與作答工作仍不同，不共用只按 `type` 篩出的候選池。每題滿分由其槽位決定，不從 `source.section` 抄分數；大題總分為所選槽位加總，卷面總分必須精確等於100。題目保留原有空格及配對項數，不能為配分拆題或任意增減作答項。

配分是供家長對答案的題目滿分，本票不新增自動批改。多空、表格、配對及勾選題不由系統擅自推定「每空平均幾分」；部分給分由家長依題意及解析判斷，開放題的範例不是唯一合格答案。答案卷需列出能判斷考點與答案的解析，不能以配分掩蓋題意不清。

## 配置管理與來源依據

後續實作於指定資料根目錄新增 `profiles/`，每個啟用範圍／科目只有一份正式配置；開發與測試用 `examples/profiles/` 或隔離 fixture，不向正式資料寫示範。配置和候選關係是題庫內容的一部分，與程式、範圍分類及近重資料以同一固定版本建置，不把具體配額硬寫在前端元件或從原型 HTML 推導。

每份配置有穩定識別、修訂版本、完整考試範圍、依序大題及槽位、題數與滿分、參照原題及來源核對證據、候選 ID／題組變體清單、各槽位考點與難度約束、作答項數及版面條件。內容雜湊納入生成識別；配額、槽位、候選、來源或衝突資料變更都使舊結果的驗證失效。每個槽位的候選必須明列並核對，不用自由文字搜尋、科目總題數或「大概同單元」代替。

參照原題用來固定考點、難度、必要資訊與作答工作；新題合格仍須依 #46 驗證，不因 `derivedFrom` 正確就自動進入所有同題型槽位。數學每槽核對運算、位數、進退位、整除、單位及步驟；語文核對字詞程度、句型與材料理解；自然／社會核對條件、圖表、因果與角色關係。各槽參照集合固定後，整卷的考點分布及難度結構亦固定，不再另抽「容易／困難」標籤或要求原題／新題比例。

## 同源、近重與題組互斥

對獨立原題，來源集合是它自己的 ID；對新題，是其 `derivedFrom` 所列的全部原題 ID。兩題集合有交集即為同源，禁止同卷。來源不存在、不是原題或範圍不一致時先按 #46／#47 拒絕候選，不能猜測來源集合。

例：A 參考 `[x]`、B 參考 `[x,y]`、C 參考 `[y]`，A／B 與 B／C 互斥，但不能只因有 B 就把 A／C 也當同源；判斷是兩題實際交集，不是將整個關係圖合併成一個來源家族。不同原題來自同一份原卷不自動互斥。每題 ID 在整卷也只能出現一次。

題組另以原題組 ID 判斷材料來源：原組與任何衍生組、或從同一原組衍生的不同組，禁止共卷。這個限制作用於不同的題組實例；同一組內可選多個不同成員，不會因共用材料就互相排除。同一組只使用一份材料、放在同一大題連續排列；不可將兩個衍生組的成員拼回一組。

已確認近重以資料根目錄的 `selection-conflicts.yaml` 保存成對題目／題組 ID、原因與版本，與配置一併檢查參照存在性並編譯成網站可用的互斥資料。完全相同的作答內容也須排除：比較題幹、選項、材料及作答結構，不能因 ID、姓名或項目順序不同就視為全新內容。正規化不能刪除數字、單位或數學運算而誤殺實質新題。單一相似度閾值不是語意判定，疑似但未決的候選先不進入啟用清單，交回本機內容核對。

近重關係同樣按已確認的配對判斷，不自行假設傳遞性；只有已確認整組互為近重時才展開其全部配對。題組近重須另記錄已確認的成員對應，供重抽差異計算，不能只因材料相似就把所有成員視為同一道題。共用一段必要材料而考不同內容，不等於近重；是否直接洩漏其他小題答案則另行核對。資料庫缺少一條近重配對不構成品質證明，配置入選前仍須依 #46 核對候選及題組。

題組候選以「材料＋已核對成員子集」登記為可選變體。閱讀變體分別恰有3／2／3題，型別、考點、每題配分及材料長度均符合相應槽位；可以節選較大的原組，但不能依賴沒印出的其他題目或因節選造成提示洩漏。瀏覽器選擇核對過的變體，不任意拼湊未核對的成員子集。材料不能切離成員，材料不計題數或分數；配對題與整張表仍不可節選其內部項目。

## 抽題與可行性

同一個純資料選題核心供建置驗證與網站使用，輸入為已核對的配置、固定版本題庫與衝突資料，輸出為完整有序的題目／材料／配分或明確失敗；介面不接受臨時改題數、改單元或放寬限制。網站不需要 AI、資料庫或伺服器寫入。

先按 #47 取得合格候選，再依槽位過濾；以隨機種子打亂候選順序，做整卷限制搜尋與回溯，不能各大題獨立抽完才隨便刪掉衝突題。原題和新題同樣參與候選，不保留比例，也不優先消耗某個來源。隨機指候選探索順序有變化，不宣稱所有可能試卷等機率。

成功必須有一份完整見證：每個槽位恰好一題、閱讀變體符合小題數與材料規則、無 ID 重複／同源／近重、題目順序與大題不變、滿分100、圖片及版面條件有效。只有單槽有足夠題目或總題數夠不能證明可行；多槽競爭同源題也可能無解。建置可保存可行見證，但不以它推算所有不重複完整卷的數量。

搜尋必須有限：每次最多展開100,000個部分配置狀態，計數方式與上限隨核心版本固定；相同種子及完整輸入可重現候選順序和結果。窮盡所有合法候選仍無完整見證才回報「不足一份完整卷」；達上限則回報「組卷未完成，請重試或回報」，不能假裝已證明缺題。載入／資料錯誤另報失敗，不偽裝成不足。啟用與否依已完成的配置驗收及可行性見證，不讓未證明可行的設定開放操作。

不足報告須區分：槽位候選不足（指出大題、考點、所需／合格數與差額）；所有單槽看似足夠但同源／近重／題組互斥造成整卷無解（列出受影響槽位及具體衝突，不編造單一「補N題就好」）；格式或圖片錯誤；來源、候選或列印尚未核對。網站顯示可理解的原因與可採取動作，本機保留 ID 及疑點詳細證據。不得靜默減題、跨範圍借題、用疑點補缺、改用其他題型，或啟動正式補題。

瀏覽器結果是當次操作的試卷狀態，不自動寫成正式 `papers/` YAML。正式現成卷也必須通過同一配置檢查，不能把既有練習卷直接升格；不合格試卷的公開輸出依 ADR 0006 停用。將來需要本機保存一份正式試卷時，須另經既有寫檔與整份資料驗證流程，不把瀏覽器「產生成功」當成已入庫或已部署。

## 重抽差異、狀態與重現

首次組卷不要求與其他人的卷子不同。重抽以同一配置與同一資料／衝突版本中，**上一份成功且仍合格的試卷**作為比較基準；不承諾本次與所有歷史卷互不重複，頁面重新載入後若沒有上一卷狀態，就按首次組卷處理。

N 為固定配置的題目 ID 數，門檻為 `ceil(N/3)`，即16／14／12／12／9題。相同題目換位置、選項調序、只換材料顯示順序都不計變更。跨 ID 但內容相同或已確認近重也視為未換；有多個對應時，以新舊卷能配成最多「相同／近重題」的一對一對應數 M 為準，變更數為 `N-M`。材料本身不另加變更題數，配對或表格仍各以一題計。僅共用原題但實質換數字／情境、已通過品質核對的新題可以算不同，不能只因同源就否定跨卷差異。

差異門檻須在整卷搜尋時一起求解，不能抽完後改報較小門檻。未達門檻不回傳成功；若窮盡後證明無解，說明「可組完整卷，但無法達成本次重抽差異」。只有確實求得最大可換題數時才報該數字；只找到某個較小結果或達搜尋上限不能稱為最大值。上一卷仍合格時保留它及其答案／列印狀態，不用失敗候選替換或先清空。

題庫、配置或衝突版本改變時，上一卷不得沿用舊資格結果：先重驗其 ID、內容、疑點與整卷配置。來源已變或不合格時停用舊卷列印，要求以新版本重新組卷；即使仍合格，也將新版本操作明確視為重新開始，不宣稱滿足跨版本重抽保證。載入失敗時不得混用新候選與舊衝突資料。

生成結果記錄配置識別／修訂、題庫與衝突內容雜湊、核心版本、種子、上一卷識別、所選槽位／ID／材料與配分及結果雜湊。相同完整輸入和種子必須重現相同結果；不能只記種子就聲稱可重現。可在本機診斷匯出這些非憑證資料，不新增後端紀錄或追蹤服務。

每次操作有獨立請求序號；只有目前仍有效的請求能更新畫面，快速重抽或切換科目後遲到的結果不得覆蓋新結果。計算候選與已成功卷分開保存，只有整卷驗證成功才一次替換成功狀態；失敗不覆寫前一卷，也不重複發布或寫檔。

## 圖文、作答空間與列印

有圖的原題仍可直接入選完整卷，不能與 #46「圖題不可衍生」混淆。保留附圖、圖片選項、欄標題、材料、注音、四線格、每題作答項數與 `space`；不能為湊頁數縮小字級、裁切材料或消除作答空間。英語配對整板不拆頁，題組至少保持材料在所選成員之前及既有連續排列規則。

配置候選核對需包含代表性最長材料、最多作答項及含圖版本，並保存通過的紙張／方向與版面限制。成功選題與可列印就緒是兩個狀態；DOM、樣式、字型或圖片未就緒，或版面檢查失敗時，不啟用列印、不顯示已完成列印驗收。不能只通過單題 schema 就宣稱整卷可印。

國語維持既有橫向紙張、直排文字及 A4／A3 選擇；其他科目不在本票更改既有排版方向。#49 承接完整卷正常／不足／失敗／載入／列印未就緒流程與實際 PDF／視覺／人類驗收，不從原型的大題隨機搭配推導正式抽題保證。題組或新增圖文形式完成後做整卷列印驗證，不為每道普通文字題重建列印站。
