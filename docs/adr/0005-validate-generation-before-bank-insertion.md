# 新題整批驗證後才加入題庫

本機 AI 產生的新題若先寫進題庫、再修到檢查通過，會因題目預設可用而把未完成內容提前納入容量；重跑另取檔名也會重複入庫。我們選擇在題庫外準備及驗證整批候選題，再由單一寫入者以不可覆寫的方式一次加入一份完整新題庫檔，同批重跑沿用原識別與結果；不增加逐題確認欄位，也不改 ADR 0003／0004 的疑點及整組衍生規則。相較直接寫入後補救，這需要操作紀錄、排他寫入與故障復原，但把半成品排除在現有唯讀載入器之外，無須讓每個讀取端理解批次狀態。

詳細輸入、品質、發布與回復契約及後續實作驗收見[本機 AI 新題與入庫契約](../question-generation-contract.md)。這是 #46 的決策；交易寫入器及品質檢查補強尚未實作，現有 skill 不代表已符合此契約。

**Falsified if:** 必須在同一批不可分割地更新多份既有題庫或附圖，或無法讓題庫寫入者及一致性讀取共用排他協定；屆時須重新設計資料版本與發布邊界，不能改回先寫半成品再驗證。
