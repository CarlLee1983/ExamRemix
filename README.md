# ExamRemix

把手機拍的考卷照片或 PDF 交給 AI agent 分析，只保留題目（去除已作答的筆跡），存成結構化題庫；再由 AI 參考原題生成同題型的新題目，最後在本機純靜態網頁上依題型排版，輸出 A4 / A3 可列印的考卷。

## 功能目標

- **匯入**：在 Claude Code 等 AI agent 中分析照片 / PDF，區分印刷題目與手寫作答，只保留題目
- **生成**：參考原題生成新題目，並附上答案與解析
- **輸出**：依題型（選擇、是非、造句、數學問答……）套用不同版面與作答空間；網頁可切換有答案版，列印預設為無答案版，另可輸出答案卷供家長對答

## 已定方向

| 面向 | 決定 |
| --- | --- |
| AI 執行方式 | 在本機的 AI agent（Claude Code）內執行，不在網頁呼叫 API |
| 網頁 | 純靜態網站，僅本機使用 |
| 題庫格式 | YAML（建置時以 schema 驗證後轉成 JSON） |
| 數學式 | LaTeX 子集，以 KaTeX 渲染；直式計算等以結構化區塊表示 |
| 紙張 | A4 / A3，以 CSS `@page` 控制 |

詳細設計與決策紀錄規劃中，之後收錄於 `docs/`。

## 隱私

原始考卷照片 / PDF 放在 `inputs/`，已被 `.gitignore` 排除，不會推上 GitHub。
